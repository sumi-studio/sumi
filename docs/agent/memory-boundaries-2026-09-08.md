# Memory replacement boundaries

The user's Decision Inbox answer on 2026-09-08 (request
`VXMUs1nokHLPlEoccjM4jfvNPqht1Dja`, response
`Q3L9Ij7CRG94YQVtMdmEwnp_pAUkoLRO`) settles the boundary for upper-layer
compression. It supersedes the proposed choice between selected experience and
importing current understanding from elsewhere in the context.

The compressing continuation retains the same parent context. Knowing later
experience does not authorize copying it into an earlier replacement.

For L0→L1 and L1→L2, preserve chronological placement and do not import content
from other retained L0/L1 chunks into the replacement. The selected source
chunks supply what is being compressed; they are not excluded merely because
they are currently in the upstream layer. The exclusion concerns experience
that remains outside that selected replacement. Later corrections retained
elsewhere must not become facts supposedly known at the earlier point.

The user subsequently clarified L2-internal reintegration in the main
conversation: material already present in L2 may be reorganized without strict
chronological ordering. Content retained in L1 or L0 must not be imported into
that reintegration. This permits organization within existing L2, not expansion
of its information sources into the upstream layers.

The user also proposed letting the compression fork see completed but unpromoted
batches as promoted. This is a design question under discussion, not an accepted
change to the full-parent fork contract. Evaluate candidate visibility separately
from replacing the actual parent prefix, preserving original selected source and
distinguishing speculative candidate text from committed memory.

Implementation and evaluation must distinguish full-context access from the
provenance and chronological scope of the text actually substituted. Do not
replace the full-parent fork with an isolated summarizer to enforce this rule.
This boundary does not require compulsory reflection, notes, or a personality
ritual.

The user approved trying the comparison, while emphasizing that useful evidence
requires a long run resembling real operation. Short probes establish mechanics
and obvious failures, not long-term superiority. Compare initial changed-prefix
cost with subsequent reuse of that same prefix; a speculative promoted prefix
may itself receive cache hits while retained. Record actual reported cache usage
and elapsed intervals, rather than assuming every such fork is a cache miss.
Preparing this experiment does not switch production to speculative promotion.
