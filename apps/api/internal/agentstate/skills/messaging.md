# Messaging の使い方

Messaging は、人と秘書がチャンネル・スレッド・DM で話すアプリです。
ここでは複数の操作の関係を説明します。正確な引数、返却値、実行条件は
その時点のツール定義を参照できます。ガイドに登場するツールでも、現在の
ツール一覧にないものは実行できません。

## 会話の場所を開く

届いたメッセージには発言者と場所が付きます。`workspace_id` は Workspace、
`place_id` はチャンネル・スレッド・DM、`message_id` は個々のメッセージを
指します。別の場所で同じ名前が使われていても、ID は別です。

場所の一覧や未読状況は `messaging.overview`、ある場所の参加者と会話は
`messaging.open`、内容を探す場合は `messaging.search` で読めます。履歴が
複数ページある場合は、結果が返す続きを指定して読みます。秘書自身の過去の
経験を読む `conversation_history` と、共有アプリに今ある会話を開く操作は
別の読み先です。

## 投稿と返信

`messaging.send` で指定した場所に、自分の発言として投稿します。
特定の発言への返信は同じ場所の `message_id` を `reply_to` に入れます。
既存の発言を編集するのは `messaging.edit_message`、撤回するのは
`messaging.delete_message` です。削除しても、その位置には削除済みの表示が
残ります。編集・削除にはアプリの本人確認やモデレーション権限が適用されます。

文章を考えているだけでは Messaging に投稿されません。会話への参加、返信の
タイミングや内容は、その場のやり取りに合わせて判断できます。

## 添付を読む・送る

受信時の添付一覧は名前、種類、サイズなどの情報です。中身のバイト列を読む
操作は `messaging.open_attachment` です。場所、メッセージ、添付の3つの ID を
使います。テキストは `content_text`、バイナリは `content_base64` に返ります。
`has_more` が true のときは `offset + returned_bytes` を次の offset にします。

小さなファイルを送る場合は `messaging.upload_attachment` で送り先の場所へ
下書きの添付としてアップロードし、返された添付 ID を `messaging.send` の
`attachments` に渡します。アップロードしただけでは投稿されません。
ツールの容量制限は1ファイルだけでなく、同じ操作ラウンド全体にもかかります。

## 通知の届き方を変える

`messaging.notification_settings` は自分の通知設定を読み、変更する操作です。
フィールド省略は維持ですが、`per_place` と `keywords` を指定するとその一覧
全体の置き換えになります。通知の設定と、届いた発言へ実際に返事をするかの
判断は別です。
