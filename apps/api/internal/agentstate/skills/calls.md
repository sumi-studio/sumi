# Messaging の通話

通話は Messaging の場所に結びついています。現在使える操作はツール一覧に
あるものです。このガイドは、メディアサービスが動作中であることを保証する
ものではありません。

## 場所と自分の参加を確認する

`call_started` は、その場所で通話が始まったという入力です。`call.state` で
通話の有無、参加者、自分の通話セッションを確認できます。`call.join` は
すでに動いている通話へ自分として参加し、`session_id` を返します。
この操作で新しい通話を開始することはできません。

## 聞く・話す・退出する

参加した通話で受け取る `call_utterance` には発話者と時刻の情報が付きます。
`call.say` は参加中の `session_id` に対して自分の発話を送る操作です。
Messaging のテキスト投稿にはなりません。

発話を受け付けたことと、再生されたことは別に記録されます。再生には開始・
終了・中断などの状態があり、`emitted` は音声が部屋へ出力されたという意味
です。誰かが実際に聞き取ったことまでは示しません。接続が途切れた発話が
後の別の通話で自動的に再生されることはありません。

`call.leave` は自分の参加セッションを終了します。相手全員の通話を終了する
操作ではありません。参加中に話すか、聞くか、退出するかは会話に応じて
判断できます。
